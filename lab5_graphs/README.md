## Требования

- **CMake** 3.14 или новее
- **Компилятор C/C++**: Visual Studio 2022 (MSVC) или MinGW на Windows

## Сборка (Windows, PowerShell)

Откройте терминал в папке `lab5_graphs` и выполните:

```powershell
cd C:\Users\dkita\AandSD\lab5_graphs

# один раз: настроить проект
cmake -S . -B build

# собрать программы
cmake --build build --config Release --target main_app unit_tests benchmarks
```

После успешной сборки появятся файлы:

| Программа      | Путь |
|----------------|------|
| Основная       | `build\Release\main_app.exe` |
| Тесты          | `build\Release\unit_tests.exe` |
| Бенчмарки      | `build\Release\benchmarks.exe` |

Если папки `build` ещё нет или сборка «ломается» после правок, можно пересоздать её:

```powershell
Remove-Item -Recurse -Force build
cmake -S . -B build
cmake --build build --config Release --target main_app unit_tests benchmarks
```

## Запуск основной программы

```powershell
cd C:\Users\dkita\AandSD\lab5_graphs
.\build\Release\main_app.exe
```

Программа спросит:

1. **Откуда вводить граф** — `1` с клавиатуры, `2` из файла  
2. При выборе файла — имя файла (например `example_graph.txt`)  
3. **Стартовая вершина** — номер вершины, от которой считаются расстояния  
4. **Куда вывести результат** — `1` в консоль, `2` в файл  

### Формат входного файла

Первая строка: число вершин `V` и число рёбер `E`.  
Далее `E` строк: `u v w` — ребро между вершинами `u` и `v` с весом `w`.

Пример (`example_graph.txt`):

```
4 5
0 1 1
1 2 2
2 3 3
0 2 10
2 1 2
```

### Пример сеанса с файлом

Вводите по очереди (после запуска `main_app.exe`):

```
2
example_graph.txt
0
1
```

Ожидаемый вывод в консоль:

```
0: 0
1: 1
2: 3
3: 6
```

(до вершины 2 кратчайший путь: 0 → 1 → 2, расстояние 1+2=3)

### Сохранение результата в файл

При ответе `2` на вопрос о сохранении укажите имя, например `result.txt`.  
Формат строк: `вершина: расстояние` или `вершина: inf`, если вершина недостижима.
