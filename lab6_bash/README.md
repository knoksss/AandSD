Скрипт `main.bash` ищет дубликаты указанного файла среди остальных файлов с тем же расширением и удаляет совпадения.
## Задача

Дан один файл (например `notes.txt`). Нужно пройтись по всем файлам в текущей директории с таким же суффиксом, сравнить их с исходным и удалить те, что совпадают побайтово. Сам исходный файл не трогаем.

## Запуск

```bash
chmod +x main.bash
./main.bash notes.txt
```

Один аргумент - путь к файлу-эталону. Если аргументов не то количество, файла нет или у имени нет расширения - скрипт пишет ошибку и выходит с кодом 1.

## Как работает

1. Берётся суффикс из имени (`notes.txt` - `txt`).
2. `find` собирает все обычные файлы вида `*.txt` в текущей папке (включая подкаталоги).
3. Для каждого файла, кроме эталона, вызывается `cmp -s` - тихое сравнение без вывода diff.
4. При полном совпадении файл удаляется через `rm`, в консоль пишется, что удалили; если отличается - просто «отличается».
5. В конце выводится, сколько файлов убрали.

## Пример

```
$ ./main.bash a.txt
Целевой файл: a.txt
Ищем файлы с суффиксом .txt ...

Совпадает: ./copy_a.txt - удаляем
Отличается: ./other.txt

Готово. Удалено файлов: 1
```

## Вывод

В ходе работы реализован bash-скрипт, который по заданному эталонному файлу находит среди всех файлов с тем же расширением в текущей директории (включая подкаталоги) полные побайтовые копии и удаляет их, не затрагивая исходный файл.
